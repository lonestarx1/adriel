역할리드 AI 엔지니어 (설계 · 개발)
기술 스택Python, LangGraph, OpenAI, Gemini, ElevenLabs, ffmpeg
주요 업무
  • 영상 수집 → 음성 추출 → 음성 인식 → LLM 에이전트 번역 → 웹 검색 기반 번역 검증 → 보이스 클로닝 → 더빙 음성 생성까지 이어지는 파이프라인 설계
